# Claude Prompt vs Project vs Skills

Interactive decision guide for choosing between Claude **prompts**, **projects**, and **skills**.

## Open locally

```bash
# from repo root
python3 -m http.server 8765 --directory coding/prompt_vs_project_vs_skills
```

Then visit [http://localhost:8765](http://localhost:8765).

## What it covers

| Layer | Use when |
| --- | --- |
| **Prompt** | One-off work: speak with Claude now and move on |
| **Project** | Keep shared context across a few chats in one body of work |
| **Skills** | Teach Claude a reusable procedure that works across chats and projects |

Tap the Prompt / Project / Skills chips to highlight a column.
